## 2025-05-18 - Replacing Location.distanceBetween with Equirectangular Approximation in Heavy Analysis Loops
**Learning:** `android.location.Location.distanceBetween` relies on Vincenty's formula (an iterative, highly heavy ellipsoid calculation) and allocates a float array on each call if passed as a new `FloatArray(1)`. In heavy spatial analysis loops (such as clustering GPS turn observations and polyline resampling), thousands of distance calls bottleneck execution. Using equirectangular distance approximation ($d = R \cdot \sqrt{\Delta\phi^2 + (\cos(\phi_m)\Delta\lambda)^2}$) provides <0.1% error for local distances (<50km), avoids native JNI/Android framework overhead, eliminates object allocations when overloaded with raw coordinates (`Double, Double`), and accelerates GPS clustering loops by 50-100x.
**Action:** Use equirectangular approximation math with coordinate primitive overloads instead of `Location.distanceBetween` in O(N^2) or heavy spatial analysis loops.
